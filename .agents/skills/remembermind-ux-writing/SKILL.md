# Propósito

Hacer comprensible la acción y su resultado con lenguaje directo, humano y profesional, conservando significado y terminología del dominio.

# Cuándo usar

Labels/headings/hints/placeholders, tooltips, acciones, errores, advertencias, mensajes críticos, empty states, confirmaciones y resultados.

# Cuándo NO usar

Marketing general, edición de manuales completos o generación de consejos/diagnósticos clínicos sin fuente aprobada.

# Fuentes que debe consultar

Leer el [contrato compartido](../../../docs/frontend/CONTRATO_VISUAL_UX_UI.md) al iniciar una tarea de esta especialidad; reutilizarlo si ya se leyó. El [pipeline](../../../docs/frontend/STACK_SKILLS_UX_UI.md) determina orden y selección, sin cargar etapas ajenas.

Contrato terminológico compartido, estado/resultado/backend y documentación funcional. Inspeccionar fuente de cada mensaje; el copy no amplía las capacidades del botón.

# Workflow obligatorio

1. Inventariar textos visibles con estado/acción/origen. Distinguir postulante, residente, usuario, personal y contacto.
2. Redactar acción explícita y mensaje que responda qué pasó, a quién afecta y qué puede hacer la persona; usar [el catálogo de copy](references/writing-patterns.md).
3. Separar error técnico, validación, advertencia e interpretación clínica. Informar de severidad existente sin alarmismo ni rebaja.
4. Conservar layout de referencia aprobado adaptando solo contenido. Revisar labels asociados, placeholders auxiliares, largos y pronunciación accesible.
5. Verificar éxito contra resultado backend, empty contra causa real y error contra recuperación posible; entregar textos finales y fuentes sin inventar datos.

# Reglas no negociables

Aplicar gobernanza de BDD, terminología, autoridad visual y UX GAP DETECTADO del contrato común. No reemplazar residente universalmente por paciente. No borrar matices clínicos para simplificar. No exponer SQL/stack/secrets ni afirmar registro, notificación o intervención no confirmados.

# Criterios UX

Directo, humano, profesional, preciso, sin condescendencia ni tecnicismo innecesario. Acciones identifican verbo y objeto; confirmación describe consecuencia. Empty explica ausencia y siguiente acción autorizada.

# Errores frecuentes que debe evitar

Error./Valor incorrecto./Operación exitosa.; OK/Aceptar/Sí ambiguos; éxito anticipado; mostrar advertencia como consejo médico generado; llamar familiar a todo contacto; ocultar razón de disabled.

# Definition of Done

Copy cubre estados aplicables, conserva terminología/hechos y señala acción de recuperación real. Alertas tienen fuente y fuerza apropiadas; textos caben y se leen con accesibilidad sin alterar estética aprobada.

Informar ANTES, PLAN, IMPLEMENTACIÓN y VERIFICACIÓN según el alcance; distinguir lo comprobado de lo pendiente.
